# NFC 付款切換 DEMO

這是給「NFC 付款切換」看的**可點介面示範頁**，不是已安裝的 App，也不會真的改手機設定。

實際的 App 不能偷偷改系統的預設感應付款應用程式，只能一鍵打開系統「預設感應付款」頁（`Settings.ACTION_NFC_PAYMENT_SETTINGS`），由你選「錢包」（OPPO 錢包，刷門禁）或「Google 錢包」（付款）。

示範內容：

- 桌面小工具：兩個大按鈕「刷門禁（OPPO 錢包）」「付款（Google 錢包）」，以及「上次選擇」（示意；App 無法可靠讀取系統目前的預設）
- 下拉快捷開關裡的「NFC 付款切換」磁貼
- App 主畫面：NFC 狀態、開啟 NFC 設定、使用教學、可選的「切到 Google 錢包後提醒切回門禁」
- 點按鈕會出現模擬的系統設定頁，選好後會回到上一頁並更新「上次選擇」
